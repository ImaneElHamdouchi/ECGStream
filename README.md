# ECGStream

[![CI](https://github.com/ImaneElHamdouchi/ECGStream/actions/workflows/ci.yml/badge.svg)](https://github.com/ImaneElHamdouchi/ECGStream/actions/workflows/ci.yml)

ECGStream is an educational C project for analyzing synthetic ECG signals from CSV files.

It demonstrates low-level programming concepts such as file parsing, dynamic memory management, circular buffers, moving-average filtering, R-peak detection, RR interval analysis, and JSON report generation.

Disclaimer: ECGStream is not a medical device and is not intended for real patient care. The ECG files generated by this project are synthetic and only used for software testing.

## Features

- CSV ECG parsing
- Circular buffer implementation
- Moving-average signal filtering
- R-peak detection
- Heart-rate estimation
- Bradycardia, tachycardia, and irregular rhythm flags
- JSON report output
- Synthetic ECG sample generation
- Automated shell tests

## Build

Run:

    make clean
    make

## Demo

Run:

    make demo

Example manual command:

    ./ecgstream analyze samples/normal.csv --json out/normal_report.json

## Tests

Run:

    make test

## Project Structure

    include/    Header files
    src/        Main C implementation
    tools/      Synthetic sample generator
    samples/    Generated ECG CSV files
    tests/      Automated tests
    out/        Generated reports

## Portfolio Note

This project is meant to show C systems programming applied to biomedical signal processing. It is intentionally separate from MedSandbox: ECGStream focuses on signal analysis, buffers, parsing, and algorithmic processing rather than Linux sandboxing.
